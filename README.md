# 马子欣｜AI 应用与全栈作品集

这是一个纯静态作品集网站，入口为 `index.html`，使用 HTML、CSS 和原生 JavaScript，无需数据库或 Docker。

## 本地预览

双击 `打开作品集.bat`，或在本目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 发布

可用 GitHub Pages 免费发布。把本目录作为独立公开仓库上传，在 **Settings → Pages** 中选择 **Deploy from a branch**、`main`、`/(root)`。仓库首页为 `index.html`。

主要视频已经准备成适合网页播放的 MP4。少数高码率原片保留在本地并由 `.gitignore` 排除；网页使用同名 `-web.mp4` 优化版本。原视频未被覆盖。

## 更新内容

- 项目介绍、视频与 GitHub 链接：`content.js`、`video.js`
- 页面交互：`app.js`、`case.js`、`common.js`
- 布局和样式：`styles.css`
- 图片、视频和 PDF：`assets/`

注意：GitHub Pages 是公开网站。发布前确认电话、邮箱、照片、成绩单及项目材料都适合公开展示。
